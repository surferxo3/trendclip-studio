# ADR-002: Original launch-day explainer

- Status: Accepted for original-graphic mode; source mode is separately authorized
- Date: 2026-11-19

## Context

Downloading game footage, trailers, logos, or commercial music creates rights and input-parsing risk and is unnecessary for demonstrating the pipeline.

## Decision

Render only original geometric visuals, typography, and locally synthesized audio. Use a launch-day factual script supported by official Rockstar pages. Disclose that the output is an original graphical explainer, not gameplay.

## Consequences

Provenance is simple and auditable. A separate source-clipping workflow may use downloaded video only after per-source reuse confirmation. Both modes still require human policy/legal review before posting.
